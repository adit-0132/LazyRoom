# ImageToolbox filter parity matrix

Generated by `scripts/gen_docs.py` from the registry and the per-group port reports in `docs/dev/port_reports/`. *faithful* = same algorithm as ImageToolbox (ported from its actual Kotlin/C++/Rust/GLSL/G'MIC sources); *approximate* = deviation explained in notes; *not ported* = missing.

Every filter is an operation `filter.*` usable via MCP (`edit_project` / `apply_to_file`), CLI (`--op filter.x`), SDK and GUI (Filters category). Platform: pure Python/numpy/OpenCV/numba ports run wherever LazyRoom runs; G'MIC filters need the G'MIC CLI (bundled in release builds, or installed separately). Tests: `tests/itb/test_<group>.py` + `tests/test_ops_smoke.py` (every filter, defaults + parameter extremes + RGBA + determinism).
