# CLI reference

Generated by `scripts/gen_docs.py`. Output is JSON when stdout is not a terminal or with `--json` (`{"ok": true, "result": …}` / `{"ok": false, "error": …}`).

Exit codes: 0 ok · 1 partial batch failure · 2 invalid input · 3 not found · 4 decode/encode · 5 path/permission · 6 backend missing · 7 resource limit · 8 timeout · 9 cancelled · 10 nothing to undo/redo · 11 operation failed · 70 internal error.

```text
usage: lazyroom [-h] [--json] [--pretty] [--config CONFIG] [--version]
                  {info,formats,backends,ops,inspect,apply,project,preset,style,batch,tools,intent,call,mcp,gui,models,config,agent-setup} ...

AI-native image toolbox (headless CLI).

positional arguments:
  {info,formats,backends,ops,inspect,apply,project,preset,style,batch,tools,intent,call,mcp,gui,models,config,agent-setup}
    info                capabilities manifest (operations, formats, backends,
                        workflows)
    formats             supported formats
    backends            optional backends and AI models
    ops                 discover editing operations
    inspect             metadata, statistics and style analysis of an image
    apply               apply operations / a preset / a steps file to an image
                        and export
    project             non-destructive projects (.lazyroom)
    preset              looks and presets
    style               style analysis and reference matching
    batch               process many images with one pipeline (runs in the
                        foreground)
    tools               utility tools
    intent              translate a natural-language request into edit steps
    call                call any API command with JSON arguments
    mcp                 run the MCP server
    gui                 launch the desktop application
    models              optional AI models
    config              show or edit configuration
    agent-setup         print MCP registration snippets for AI clients

options:
  -h, --help            show this help message and exit
  --json                force JSON output (default when stdout is not a TTY)
  --pretty              indent JSON output
  --config CONFIG       path to a config.json
  --version

examples:
  lazyroom ops list --category adjust
  lazyroom ops describe adjust.color_grading
  lazyroom apply in.jpg out.jpg --op adjust.exposure ev=0.4 --op effect.grain amount=20
  lazyroom apply in.jpg out.jpg --preset warm-70s-film
  lazyroom project create in.jpg --save edit.lazyroom --op adjust.white_balance temperature=15
  lazyroom project preview edit.lazyroom --out preview.jpg --compare side_by_side
  lazyroom style match in.jpg reference.jpg --save matched.lazyroom --export matched.jpg
  lazyroom batch ~/Pictures/trip --output-dir out/ --preset faded-analog --normalize both --wait
  lazyroom tools run palette input=photo.jpg count=5
  lazyroom intent "warm, faded 70s film look with muted greens" --image in.jpg
  lazyroom mcp                      # MCP server on stdio (for Claude Desktop/Code, Cursor, ...)
  lazyroom call ops.list '{"query": "vignette"}'

```

## `lazyroom batch`

```text
usage: lazyroom batch [-h] --output-dir OUTPUT_DIR [--op OP [KEY=VALUE ...]]
                        [--steps STEPS] [--preset PRESET] [--project PROJECT]
                        [--recursive] [--naming NAMING] [--format FORMAT]
                        [--quality QUALITY]
                        [--metadata {keep,keep_no_gps,strip}] [--overwrite]
                        [--skip-existing]
                        [--normalize {none,exposure,white_balance,both}]
                        [--match-reference MATCH_REFERENCE]
                        [--workers WORKERS] [--dry-run]
                        inputs [inputs ...]

positional arguments:
  inputs                files, folders or glob patterns

options:
  -h, --help            show this help message and exit
  --output-dir OUTPUT_DIR
  --op OP [KEY=VALUE ...]
                        add an operation step, e.g. --op adjust.exposure
                        ev=0.5 (repeatable)
  --steps STEPS         JSON file with a list of steps
  --preset PRESET       preset / look id
  --project PROJECT     use this .lazyroom's pipeline
  --recursive
  --naming NAMING
  --format FORMAT
  --quality QUALITY
  --metadata {keep,keep_no_gps,strip}
  --overwrite
  --skip-existing       resume: skip files whose output exists
  --normalize {none,exposure,white_balance,both}
  --match-reference MATCH_REFERENCE
  --workers WORKERS
  --dry-run

```
